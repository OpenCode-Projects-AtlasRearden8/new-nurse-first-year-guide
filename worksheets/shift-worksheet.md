# Shift Worksheet (Daily Brain Sheet)

**Education only — not medical advice.** Blank template. Follow your facility's rules about what may be written on paper and where it goes at shift end. Fill patient identifiers only where your employer's policy says you may.

Print one per shift. One block per patient, sickest at the top.

```
Date: ______  Shift: D / N   Unit: ________  Assignment: ___ patients   Partner/charge: ________

PATIENT BLOCK #1
Room: ____  Initials(____): __  Dx: ____________
Code status: ____  Allergies: ___  Isolation: ___
Plan today (one line): ________________________________
Latest vitals:  HR ___  BP ___  RR ___  SpO2 ___  T ___
Labs flagged today: ________________________________
Tasks + times: ______________________________________
Watch-fors (2 lines, decision-shaped):
  If ______________________ then ______________________
  If ______________________ then ______________________
Notes space:  ________________________________________
```

*(Duplicate the block for each patient — or print the grid at the end.)*

## During shift, add in four streams

| Stream | Mark it like this |
|---|---|
| Numbers | New vitals next to old with ↑/↓ |
| Orders | Exactly as said + time you received it |
| People | One line: who, what, time (family, provider, case mgmt) |
| Gut | ★ next to anything that nagged you — stars are your handoff list |

## End-of-shift checklist (per policy)

```
[ ] All tasks done, doc'd, or handed off with time + name
[ ] Pending labs / rides / appointments written for oncoming
[ ] Watch-fors spoken aloud at handoff
[ ] Stars (gut items) each resolved or handed to someone
[ ] Paper handled per facility policy, nothing unapproved leaves
```
