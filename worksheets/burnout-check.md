# Weekly Burnout Check (2 Minutes)

**Education only — not medical advice.** Not a diagnostic tool. A two-minute mirror, run every Sunday. See [chapter 7](../docs/07-burnout-warning-signs.html).

## Week of: __________ (run same time each week)

Rate each 1–5, where **1 = bad, 5 = good**:

| Area | Score (1–5) | One-line note |
|---|---|---|
| Energy: does sleep repair me? | | |
| Mood at work: dread level (reversed) | | |
| Detachment (reversed): do patients still feel like people? | | |
| Life outside work: food, laundry, people | | |
| Body: aches, illness, gut | | |

## Read it

```
[ ] Any three scores 1–2        → run the support plan this week; consider talking to EAP/professional
[ ] Declining 3 weeks in a row  → schedule a real conversation (manager/educator) about load
[ ] One low next to others fine → move toward that bright spot on purpose
[ ] 4–5 across the board        → note what's working; that's your pattern to keep
```

## This week's two questions (one line each)

```
What drained me most:   __________________________________________
What filled me most:    __________________________________________
```

## Small commitments for next week (pick at most two)

```
[ ] Protect sleep blocks (chapter 5 plan intact?)
[ ] Pull one plug: put ________ on pause for 30 days
[ ] One scheduled fun/contact: ________________
[ ] Hard boundaries said out loud: ________________
[ ] Reach out early (EAP / own provider / 988 if ever needed): [ ]
```

**Amber-light reminder:** one rough week is life, two in a row is a flag, three is a meeting with yourself. Early is cheap. Late is expensive.
