# STATUS — New Nurse: The First-Year Survival Guide

## What was built

An education-only manual (never medical advice) for surviving the first nursing year, delivered two ways:

- **Markdown source** — `docs/` (10 chapters) and `worksheets/` (5 printable sheets)
- **Static HTML site** — generated by `build.py` into `site/` (17 pages), stdlib-only, offline, zero dependencies

### Chapters (docs/)

1. Read this first — disclaimers, how to use, related projects
2. Orientation expectations — the ramp, phases table, week-one surprises, self-check questions
3. Asking questions without feeling dumb — look/ask/escalate rule of thirds, copyable scripts, question journal
4. Organizing report notes — patient-block layout, watch-fors as decisions, four-stream add-on, handoff hygiene
5. Preceptors and feedback — roles table, feedback loop, preceptor styles, mismatch escalation
6. Night-shift survival — Block/Split schedules, caffeine lease timing, 3-in-a-row, drive-home plan
7. Confidence math — the 100-shifts-to-comfort model, curve table, imposter two-column drill
8. Burnout early-warning signs — body/emotional/behavioral/cognitive signals, 2-minute weekly self-check, support plan
9. When to switch units — stretch-vs-fit sorting, cost side, how to move well
10. Glossary — day-one vocabulary translated, escalation phrases

### Worksheets (worksheets/)

- `shift-worksheet.md` — daily brain sheet with decision-shaped watch-fors
- `night-shift-worksheet.md` — sleep/caffeine/food/drive-home planning form
- `confidence-log.md` — 100-shift tracker with every-10 read-back
- `burnout-check.md` — two-minute Sunday mirror with read-it rules
- `feedback-notes.md` — preceptor feedback log + orientation setup

### Site generator (build.py)

- Minimal markdown renderer (headings, tables, lists with nesting, checkboxes, blockquotes, fenced code, inline bold/italic/code/links)
- Shared warm-print design; print styles for worksheets; strict CSP (`default-src 'none'`) on every page
- Education-only banner + "not medical advice" + LLC copyright footer on every generated page
- Prev/next navigation chains for chapters and worksheets
- Source validation (`--check-only`): disclaimer present, titles present, minimum counts, internal link targets resolve
- Post-build validation: every href/src in every generated page must exist inside the site tree

## How to run

```bash
python3 build.py                        # build into site/ + validate links
python3 build.py --check-only           # validate sources only
python3 -m unittest discover -s tests -v   # run the 25-test suite
```

Then open `site/index.html` in any browser — no server, no network, no analytics.

## Known gaps / honest limits

- The markdown renderer covers the constructs used by these docs (no images, no footnotes, no nested tables). Unsupported syntax renders as plain paragraphs rather than erroring.
- The "100 shifts to comfort" numbers are experience-based averages drawn from common new-nurse descriptions, not research citations.
- The burnout self-check is a self-awareness mirror, not a validated instrument; it deliberately points to professional help instead of diagnosing.
- Site styling is embedded inline per page (plus a copyable `style.css`) so the site works from any folder without a server; a multi-page CSS refactor could shave some duplication.
- No search feature; the site is small enough to skim, and the index is the search.
- External link (dylanasdale.github.io hub) appears in docs; everything else is internal or sibling-project names only.
